# Sleep Disorder Prediction

A Streamlit app that estimates the probability of a sleep issue and predicts whether the likely issue is insomnia or sleep apnea.

> This project is for education and portfolio demonstration only. It is not medical advice and should not be used for diagnosis.

## Features

- Streamlit prediction UI
- Saved scikit-learn models
- Sleep issue probability estimate
- Sleep issue type prediction
- BMI-based risk input
- Precaution guidance for insomnia and sleep apnea
- Dockerfile included for containerized deployment

## Setup

```bash
pip install -r requirements.txt
streamlit run sleepissuepredictor/app.py
```

## Docker

```bash
cd sleepissuepredictor
docker build -t sleep-disorder-predictor .
docker run -p 8501:8501 sleep-disorder-predictor
```

## Dataset

The app uses the Sleep Health and Lifestyle dataset. The model inputs include age, sleep duration, heart rate, daily steps, gender, BMI category, and whether the user works in a technical/numeric field.
